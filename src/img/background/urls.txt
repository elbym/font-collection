# Globale Hintergrundbilder für Font Cards
# ==========================================
# Bilder werden beim Build heruntergeladen und in diesem Ordner gespeichert.
# Die heruntergeladenen Dateien sind gitignored – nur diese urls.txt wird committed.
# Bereits vorhandene Dateien werden nicht erneut heruntergeladen.
# Zum Erzwingen: Datei löschen, dann npx gulp download (oder npx gulp).
#
# ── UNSPLASH (images.unsplash.com) ────────────────────────────────────────────
# 1. Foto auf unsplash.com öffnen
# 2. Rechtsklick auf das Bild → „Bild in neuem Tab öffnen"
#    Die URL beginnt mit https://images.unsplash.com/photo-…
# → Der Build setzt ?w= automatisch auf IMAGE_MAX_WIDTH (Maximalgröße in gulpfile.js).
#
# ── PEXELS (images.pexels.com) ────────────────────────────────────────────────
# 1. Foto auf pexels.com öffnen
# 2. Rechtsklick auf das Bild → „Bildadresse kopieren"
#    Die URL beginnt mit https://images.pexels.com/photos/…
# → Der Build setzt ?w= automatisch auf IMAGE_MAX_WIDTH.
#
# Format: eine URL pro Zeile, optional: eigener-name=https://...
# =============================================================================
