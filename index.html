    Persönliche Sammlung von freien Schriftarten

    Jeder hat doch eine Lieblingsschriftart, oder? ODER!?

    Dies ist lediglich eine persönliche und subjektive Sammlung von Schriftarten, die mir im Gedächtnis geblieben sind, und begann als Vorwand, um den font_specimen_generator.py (den ich Claude gebeten hatte, zusammenzubasteln) vorzuführen. Stattdessen bin ich zu einer HTML-Vorschau gewechselt.

    Diese Liste ist auch beeinflusst von Teuderun und Free Font Library

    Das Schriftmusterplakat ist stark inspiriert von (kopiert von) Schriftprobensammlung Gustav Mori an der Universität Frankfurt.

    Warum bin ich erst so spät darauf gestoßen? Claus Eggers Sørensen hat wunderbare Musterlayouts für seine Playfair -Schrift Word Tower Specimen Demo

    python font_specimen_generator.py

    Ich habe Claude gebeten, ein Python-Skript zusammenzubasteln, um eine Vorschau der Schriftmuster zu generieren, inspiriert von denen auf Wikipedia

    Derzeit werden 3 verschiedene Designs unterstützt: cremefarben, dunkel, weiß

    Beispiele:

    python font_specimen_generator.py --input ./fonts --output ./previews python font_specimen_generator.py --input ./fonts --output ./previews --theme white python font_specimen_generator.py --input ./fonts --output ./previews --width 1400 --theme cream python font_specimen_generator.py --input ./fonts --output ./previews --overwrite

    made with ❤️, 11ty and font from a lot of people.
